# Changelog

All notable changes to Neural Lab are documented here.

## 0.1.0

### Added

- Dependency-free vector memory with cosine retrieval
- Minimal memory-aware agent loop
- Prompt and context budgeting utilities
- Retrieval evaluation metrics
- Text chunking and lexical scoring
- Hybrid ranking primitives
- Memory recency decay
- Bounded LRU cache
- Structured agent tracing
- Rule-based tool routing baseline
- Synthetic retrieval dataset generation
- Persistent SQLite memory
- Retrieval benchmark and runnable examples
- Unit tests and architecture documentation
